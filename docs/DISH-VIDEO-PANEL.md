# 菜品详情关联视频面板 · 改造与验收记录

> 2026-11-12 · 本地工作副本（未 commit / 未推送 / 未部署）
> 目标：删除独立视频模块，保留真实视频搜索服务；在菜品详情里用「另一半页」临时展开关联视频。

## 1. 交互结果

1. 从「图鉴 / 菜系 / 口味」点选菜品，或直接进入菜品详情。
2. 详情页保持原页不动；点「做菜视频」后，视频面板铺在详情页的另一半：
   - 双页：从书脊向另一侧展开；
   - 单页（手机/窄屏）：整页浮起，顶部保留「收起视频」。
3. 面板自动按**当前菜品**检索，没有搜索框。
4. 视频以 2–3 列卡片网格展示；卡片是真实 B 站链接（缩略图、标题、作者、时长、简介、相关标签）。
5. 「搜索更多」保留已有卡片，按页追加、去重、平滑滚到第一张新卡片；没有更多时显示「暂时没有更多与这道菜相关的视频了。」
6. 「收起视频」只摘掉视频层，详情页、纸页内容、滚动位置和筛选状态原样恢复；再次打开同一道菜会复用已加载结果与分页。

## 2. 删除的内容与保留的服务

删除：

- 侧边书签「视频」、视频章节、视频独立路由 `/videos`（旧地址归到美食图鉴）。

保留：

- 抖音/小红书/西瓜官方搜索页入口、平台适配和外部链接逻辑。
- 新增 `GET /api/videos/dish` 与 `searchDishVideos()`，只负责“当前菜品”检索。

## 3. 当前菜品检索

请求参数：`dishId`、`dishName`、`englishName`、`aliases`、`cuisineType`、`flavorType`、`mainIngredients`、`cookingMethods`、`exclude`、`limit`、`page`。

规则：

- 优先中文菜名；没有中文名时用英文名；不把菜名、菜系、口味拼成一条长关键词。
- 搜索关键词只围绕当前菜名，例如「剁椒鱼头 做法 / 剁椒鱼头 家常做法 / 剁椒鱼头 烹饪技巧」。
- 结果必须能在标题/简介/标签/分区/作者中找到当前菜名或已确认别名；不用“同类菜系”兜底，不把川菜/湘菜整体当成本菜。
- 先做美食判断，再做当前菜品判断；过滤电脑、手机、游戏、数码、汽车、段子、盘点、搞笑等非美食内容。
- 带比较语境的结果（如「豆腐……比麻婆豆腐还好吃」）不算这道菜教程。
- 排序优先：完整菜名教程 > 家常做法 > 专业教程 > 食材处理/关键技巧 > 改良/地域变体 > 饮食文化。
- 失败时返回明确错误，页面显示「视频暂时打不开」和重试按钮；没有结果时明确说明，不用随机视频填充。

## 6. 已知边界

- 真实视频源目前只有 B 站；抖音/小红书/西瓜仍只提供官方搜索页入口，不抓取。
- B 站搜索结果会随时间变化；网络/风控失败时页面如实提示，不伪造视频。
- 卡片点击打开 B 站真实视频页，不在书页内伪造播放器；没有站内播放器。
- 手机端“单页”是画册的单页尺寸，不是全屏独立 App 页面；面板在书页内浮起，保留画册上下文。
- 数据集没有独立的「红烧肉」菜品记录；UI 测试使用现有红烧肉变体，接口的 `dishName=红烧肉` 路径已单独验证。
